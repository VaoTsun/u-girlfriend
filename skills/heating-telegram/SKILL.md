# Отправка отопления в Telegram

Берёт ту же сводку датчика, что и навык `heating-check`
(данные из `http://192.168.88.171:90/getdots`, а не с картинки графика),
и отправляет её сообщением в Telegram через Bot API.

## Когда использовать
- «отправь отопление в телеграм»
- «скинь сводку отопления в тг»
- «отопление телеграм»
- «пришли температуру котельной в телеграм»

## Быстрый путь
```powershell
# по умолчанию — Отопление (теплоноситель), за 5 минут, в личный чат
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "scripts/heating-telegram.ps1"

# другой датчик и окно
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "scripts/heating-telegram.ps1" -Preset "котельная" -Minutes 30

# проверить, что уйдёт, но НЕ отправлять
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "scripts/heating-telegram.ps1" -DryRun
```

Параметры:
- `-Preset` — алиас датчика (тот же набор, что у `heating-check`:
  `отопление`, `котельная`, `прихожая`, `кухня`, `ванная`, `бойлер`,
  `колодец`, `вольтметр`, `большой вольтметр`). По умолчанию `отопление`.
- `-Minutes` — окно «назад» в минутах (по умолчанию `5`).
- `-Server` — адрес мониторинга (по умолчанию из `config.json`).
- `-Token`, `-ChatId` — переопределить получателя (по умолчанию из `config.json`).
- `-DryRun` — сформировать сообщение и вывести его, не отправляя.

## Конфиг
Файл `config.json` рядом с навыком:
```json
{
  "token": "<bot token>",
  "chat_id": "<chat id>",
  "server": "192.168.88.171:90"
}
```
Отправка идёт в личный чат пользователя (`chat_id`). Ошибки отправки
выводятся текстом вида `Ошибка отправки в Telegram: <причина>`.

## Как это отвечать
1. Запусти скрипт и покажи пользователю, что ушло (устройство, текущее значение).
2. Если в ответе `Ошибка …` — сообщи причину (нет сети, неверный токен/chat_id).
3. Текст сообщения: моноширинный блок `<pre>` со сводкой и заголовком с датой/временем.

## Заметки по поддержке
- Скрипт сохранён в **UTF-8 с BOM** — иначе PowerShell 5.1 ломает кириллицу.
- `config.json` содержит токен бота — **не** коммитить в публичные репозитории.
- Навык зависит от `heating-check`: берёт `../heating-check/scripts/heating.ps1`.
  Если тот недоступен — печатает `Ошибка: не найден heating.ps1`.
