# Weather Forecast

Логирует прогноз погоды и фактическую погоду в одной таблице `dev.weather`.

## Таблица
```sql
CREATE TABLE IF NOT EXISTS dev.weather (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  day date NOT NULL UNIQUE,
  data jsonb NOT NULL DEFAULT '{}'::jsonb,
  updated_at timestamptz NOT NULL DEFAULT now()
);
```

`data` содержит:
```json
{
  "forecast": { "source": "openweathermap", "fetched_at": "...", "city": "Visaginas", "tmin": -1.2, "tmax": 6.4, "items": [...] },
  "actual":   { "filled_at": "...", "from": "ar.vals", "src": <id>, "tmin": -2.3, "tmax": 5.9, "samples": 288 }
}
```

## Скрипты
- `scripts/weather_forecast.py` - утренний. Берёт прогноз с OpenWeatherMap (как в `u-barn/fcast.js`), нормализует, мерджит в `data.forecast`. **Не трогает** `data.actual` если уже есть.
- `scripts/weather_actual.py` - утренний следующего дня. Считает `min(cels)/max(cels)` за сутки по сенсору из `config.json` (`outdoor_src`) из `ar.vals`, дописывает в `data.actual`.

## Конфиг
Скопировать `config.json.example` в `config.json` на проде. Временно можно использовать сенсор "банановый" (айди уточню/укажу когда будет готов).
