# Напоминания — встроены в бота «Насущное»

Фича Telegram-бота (`@zavisiskeBot`, чат владельца `5002583838`): приём
«напомни ...» и своевременная отправка. **Работает на проде (192.168.88.171)
внутри процесса `crons.js`** (дочерний `web.server.js`) — не cron: принимать
сообщения может только сам бот, у которого уже идёт polling.

## Как пользуется владелец

| Пишет боту | Бот отвечает |
| --- | --- |
| «напомни позвонить через 2 часа» | «⏰ Напомню 19.10 в 20:16 (через 2 ч): позвонить» |
| «напоминания» / «список напоминаний» | список с номерами и временем |
| «отмени напоминание 1» | «🗑 Отменил напоминание #1» |
| «напомни ...» (без времени) | подсказка с примерами формата |

По прошествии времени: «⏰ Напоминаю: <текст>» (если задержка > 5 мин —
пишет, на сколько задержалось). Порядок слов любой: «напомни через час
позвонить» тоже работает.

Понимаемые форматы: `через 5 минут/мин`, `через 2 часа/ч`, `через 3 дня/дн`,
`через полчаса`, `через 1,5 часа`, `через час` (без числа = 1 единица).

## Как устроено (u-barn)

- `ns.bot.js` — парсер `interpret()` (правила `remind*`, чистые функции
  тестируемы без бота) + хранение + таймер в `attach(bot)`.
- Хранение: `reminders.json` рядом со скриптом (в `.gitignore`, runtime).
  Файл — истина: перезапуск процесса и внешние правки ничего не теряют;
  созревшие при простое шлём сразу при старте.
- Таймер: каждые 30 с, атомарная запись (tmp+rename), неудачная отправка
  повторяется до 5 раз (`attempts` в записи).
- Лог событий: `reminders.log` рядом с файлом (принято/отправлено/не отправлено).

## Тесты без Telegram

```bash
# разбор фразы (прод или локально, из D:\_d\u-barn):
node -e "console.log(require('./ns.bot.js').interpret('напомни позвонить через 2 часа'))"

# инъекция напоминания, созревающего через 75 с (затем ждём ≤2 мин и смотрим reminders.log):
# python3 → записать [{"id":999,"chat":5002583838,"title":"ТЕСТ","ts":now+75000,...}] в reminders.json
```

Полный флоу локально — фейковый бот (EventEmitter c `sendMessage`/`onText`)
+ `attach()`: таймер на старте шлёт созревшее из файла, затем эмит сообщений
«напомни...»/«напоминания»/«отмени...». Шаблон: `test-reminders.js` (см. журнал).

## Важно для деплоя

- Деплой `ns.bot.js`: `git push` + `git pull` на проде + touch
  (`ssh ubarn171 "touch /home/vao/u-barn/web.server.js"`) — nodemon рестартит.
- **Симлинк `/home/vao/voltage → u-barn` оставлять!** После переименования
  каталога (19.10.2026) nodemon следит по старым путям `/home/vao/voltage/...`;
  без симлинка его watch мёртв и деплой не рестартит сервер (грабли — в журнале).
- Новый код подхватывает только перезапущенный `crons.js` (сам `web.server.js`
  не менялся — его рестартить не нужно, хватает перезапуска crons/web-server
  через nodemon).
