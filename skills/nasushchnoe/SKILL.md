# Насущное

Третий уровень дел Подружки (после плана дня и сезонного календаря):
**общие дела и заметки «когда-нибудь надо»**, не привязанные к дню или
сезону. Живут, пока не выполнены.

**Хранение — база данных** (с 2026-10-16):

| Что | Где |
| --- | --- |
| Таблица | `dev.nasushchnoe` (схема `dev`, база `d`, сервер `192.168.88.171:5432`) |
| Веб-страница | `http://192.168.88.171:90/nas.html` (ссылка «Насущное» в меню) |
| API | `http://192.168.88.171:90/sql?sql=dev.nasushchnoe.*` |

Колонки: `i`, `title`, `notes`, `created_at`, `done`, `done_at`.

## Три уровня дел

| Уровень | Хранение | Когда использовать |
| --- | --- | --- |
| План | `plan.txt` (навык `plan-day`) | что делаю сегодня/на неделе/на год |
| **Насущное** | **база `dev.nasushchnoe`** (этот навык) | общие дела «когда-нибудь надо»: починить насос, проводка… |
| Календарь | `cowgirl-calendar/calendar.txt` | сезонные работы, каждый год примерно в одно время |

## Команды (голосом, после слова «подружка»)

- «навык насущное **добавь** починить насос» — добавить дело
- «навык насущное **покажи**» — список с номерами
- «навык насущное **сделал** занавесочку» / «сделал номер 2» — отметить сделанным
- «навык насущное **убери** пылесос» — удалить дело
- «навык насущное **очисти**» — убрать все сделанные

## Быстрый путь (без голоса)

```powershell
$p = "skills\nasushchnoe\scripts\nasushchnoe.ps1"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -List
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Add "починить насос"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -DoneN 2
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Done "занавесочку"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Remove "пылесос"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $p -Clear
```

## Как это работает

Скрипт `scripts/nasushchnoe.ps1` ходит в endpoint `/sql` сайта на 171
(разрешённые SQL-файлы — `SQL_ALLOWLIST` в `web.server.js`):

| Действие | SQL-файл |
| --- | --- |
| список | `sql/dev.nasushchnoe.list.sql` |
| добавить | `sql/dev.nasushchnoe.ins.sql` (`$1`=title, `$2`=notes) |
| отметить/вернуть (toggle) | `sql/dev.nasushchnoe.done.sql` (`$1`=i) |
| удалить | `sql/dev.nasushchnoe.del.sql` (`$1`=i) |

Требуется работающий сайт, отдающий этот endpoint. Скрипт сам перебирает
адреса: боевой `http://192.168.88.171:90`, затем локальный dev
`http://127.0.0.1:90` (переопределяется параметром `-Api`). Данные при этом
всегда попадают в одну и ту же базу (`d` на `192.168.88.171`), поэтому
неважно, какой из серверов выполнил SQL.

Тот же API используется веб-страницей `nas.html` + `nasData.js`, так что
правки в вебе и голосом видны друг другу сразу. Номера в `-List` идут по
открытым делам (без сделанных), как и голосовой показ.
