# Журнал: зафиксировать итоги сессии

Память между сессиями: журналы решений живут в репозитории girlfriend
(память ассистента). Пути ниже — от корня girlfriend (на этой машине
`D:\_d\girlfriend`; voltage лежит рядом: `../voltage`).

## Порядок действий

1. **Собрать, что реально сделано.**
   - `git -C ../voltage status` и `git -C ../voltage log --oneline -5`
   - просмотреть дифф: `git -C ../voltage diff HEAD --stat`
   - вспомнить исправления без кода (диалоги, инциденты на сервере)

2. **Если трогал структуру БД** — перегенерировать документацию:
   ```bash
   node tools/dbdoc.js        # перегенерит knowledge/voltage-db.md
   node tools/dbdoc.js --check
   ```
   Файл `knowledge/voltage-db.md` генерится из самой базы, руками не править.

3. **Добавить запись сверху в `journal/voltage.md`** (для другого проекта —
   свой журнал `journal/<проект>.md`):

   ```markdown
   ## YYYY-MM-DD — <короткая тема>

   **Контекст:** с какой проблемой/задачей пришли.
   **Сделано:** что поменяли (файлы, коммиты, запросы).
   **Результат:** как проверили, что работает.
   **Отложено:** что не сделали и почему.
   ```

4. **Обновить README проекта** (`../voltage/README.md`): перенести пункты
   между секциями `todo:` и `done:`.

5. **Закоммитить в git** и (если менялся код) задеплоить по правилам из AGENTS.md.
