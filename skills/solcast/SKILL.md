# Solcast — сколько панель даст батарее

Прогноз и факт выработки солнечной панели (Solcast), переведённые в кВт·ч за сутки.

## Как устроено

* `crons.js` (voltage) 2 раза в сутки ходит в Solcast API (бесплатный план —
  10 запросов в сутки) и пишет прогноз на 14 дней + факт за 7 дней в таблицу
  **`dev.solcast`** с меткой `loaded_at` — история прогнозов сохраняется.
* Голосовой навык и страница `/solcast.html` читают **локальные данные**
  (`/solcast_data` -> `dev.solcast_days()` / `dev.solcast_history()`), API не дёргают.
* Сегодняшние уже прошедшие интервалы считаются по факту, будущие — по прогнозу.

## Команды («подружка навык солнце …»)

| Команда | Что делает |
| --- | --- |
| `навык солнце` | сегодня + завтра (по умолчанию) |
| `навык солнце сегодня` / `завтра` / `послезавтра` | конкретный день |
| `навык солнце на 5 дней` / `на неделю` | несколько дней |
| `навык солнце история` | точность прогноза: обещали — вышло |
| `навык солнце обновить` | дотянуть свежий прогноз из Solcast (1–2 запроса к API) |

## Файлы

* `scripts/solcast.ps1` — скрипт навыка (данные с сервера voltage `/solcast_data`)
* `config.json` — `server` — адрес web.server.js (порт 90)
